# Учебный проект по Python BankingOperationsWidget

## Описание:

Учебный проект серверной части виджета банковских операций. Виджет имеет возможность отображать 
операции клиента. 

На данный момент проект находится в разработке и будет представлен частичный функционал
## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/gsadi310d/bankingoperations…
```

## Использование:

1. Для поверки фунционала шифрования данных карт можно использовать команду:
```
python tests/test_1.py
```
2. Для поверки фунционала шифрования данных карт в зависимости от типа и форматирования даты
можно использовать команду:
```
python tests/test_2.py
```
